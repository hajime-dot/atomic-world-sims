# Atomic World Simulation

Interactive classroom simulations for secondary physics (atomic models, Bohr hydrogen, Rayleigh criterion, energy gap), originally created with Grok.

**Live demo:** https://shadow-zephyr-ember-moon.grok.me/

## Simulations

| File | Topic | Description |
|------|-------|-------------|
| [index.html](index.html) | Home | Landing page with links to all lessons |
| [models.html](models.html) | Models of the atom | Thomson, Rutherford, Bohr — and where each fails |
| [bohr-hydrogen.html](bohr-hydrogen.html) | Bohr's hydrogen | Orbits, emission, absorption, energy levels, excitation |
| [rayleigh.html](rayleigh.html) | Rayleigh criterion | Angle and viewing distance |
| [energy.html](energy.html) | Energy gap | Survival — tap the energy before it arrives |

## Notes

These HTML files are the page shells from the Grok-hosted app. The interactive simulations load JavaScript and CSS assets from the original host (`shadow-zephyr-ember-moon.grok.me`).

For the full interactive experience, open the live demo above. The files here are useful as a snapshot / reference or for hosting with adjusted asset paths if you mirror the assets.

## Classroom use

- Bohr hydrogen: orbits (r = n² a₀), energy levels (Eₙ = -13.6 eV / n²), emission/absorption, continuum ionization (excess KE).
- Suitable for DSE / secondary physics atomic world topics.
